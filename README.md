# Mon italien

Application personnelle d'apprentissage de l'italien.

## Utilisation

Le site est entièrement statique et fonctionne avec :

- HTML
- CSS
- Vanilla JavaScript
- localStorage

Aucun serveur ou backend n'est nécessaire.

## Hébergement avec GitHub Pages

1. Créer un repository GitHub.
2. Ajouter les fichiers de ce dossier à la racine du repository.
3. Dans GitHub, ouvrir **Settings → Pages**.
4. Sous **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`.
6. Enregistrer.

Le fichier `index.html` sera automatiquement utilisé comme page d'accueil.

## Données utilisateur

Les progrès, favoris et contenus personnalisés sont stockés dans le `localStorage` du navigateur.
Ils ne sont donc pas synchronisés automatiquement entre plusieurs appareils.
